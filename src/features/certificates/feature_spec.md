# CoA 번역 탭 기능명세서

## 1. 목적과 범위

- **사용자와 상황**
  식품 수출 담당 팀원이 수출국에 제출할 시험성적서(CoA)를 번역할 때 쓴다. 원본 CoA를 올리면 AI가 원본 언어를 판단해 알려주고, 담당자가 번역 언어를 고르면 AI가 원본과 같은 양식으로 번역 초안을 만든다. 담당자는 원본과 번역본을 나란히 놓고 대조해 고친 뒤 저장하고, Word나 PDF로 내보내 제출한다. 번역하지 않고 원본만 보관할 수도 있다.

- **사용자가 이 탭에서 끝낼 수 있어야 하는 업무**
  1. 제품을 고르고 원본 CoA 파일 등록 (성적서 이름은 직접 정하거나 파일 이름 그대로)
  2. AI가 판단한 원본 언어 확인, 번역 언어 선택 (또는 원본만 보관)
  3. AI 번역 초안 생성 (스캔본 포함)
  4. 원본과 번역본을 나란히 대조하며 번역본 수정
  5. 임시 저장, 저장(확정)
  6. 보관함에서 저장한 CoA를 제품·국가·검색어(성적서 이름·파일명·로트 번호)로 찾아 다시 열기
  7. 번역본을 Word·PDF로 내보내기, 원본 파일 보기·다운로드

- **이번 시연 범위**
  CoA 번역 탭 기능 전체 (아래 F1~F9)

- **기능 구성**

| 번호 | 기능 | 내용 |
|---|---|---|
| F1 | 원본 등록 | 제품과 원본 파일을 골라 등록. 성적서 이름은 직접 입력할 수 있고, 비워 두면 올린 파일 이름으로 저장. 파일 형식·크기 검사, 같은 파일이 두 번 등록되지 않게 막음 |
| F2 | 글자 읽기·원본 언어 판단 | 원본 파일에서 글자를 읽고, AI가 원본 언어를 판단해 표시한다(베트남어 등 대부분의 언어). 틀리면 담당자가 바꿀 수 있다. 스캔본·사진은 AI가 이미지를 직접 읽어 글자를 인식한다. |
| F3 | 번역 | 담당자가 번역 언어를 고르면 AI가 원본 양식(제목·표·서명란) 그대로 번역한다. 숫자·단위·로트 번호 등은 바꾸지 않는다. 제출 국가는 번역 언어에 맞춰 자동으로 붙는다. |
| F4 | 원본·번역본 대조 편집 | 왼쪽에 원본, 오른쪽에 번역본을 두고 칸별로 수정. 확대·축소, 크게 보기 |
| F5 | 숫자 대조 경고 | 원문과 번역문의 숫자·표기가 다르면 '원본 대조 필요' 경고 |
| F6 | 저장 | 임시 저장, 저장하기(확정), 원본만 저장. 저장하면 보관함에 들어감 |
| F7 | 보관함 | 저장한 원본과 번역본 목록. 제품·국가·검색어로 찾기, 고정, 정보 편집, 번역본 추가, 삭제 |
| F8 | 내보내기 | 번역본을 Word·PDF로 내보내기. 원본 파일 보기·다운로드 |
| F9 | 작업 이력 | 상태 변경과 수정 이력 확인 |

- **권한**
  관리자와 팀원을 구분하지 않는다(HOME과 동일). 로그인한 팀원은 모두 같은 권한으로 등록·번역·저장·편집·삭제·내보내기를 할 수 있다. 다른 팀원이 올린 원본과 번역본도 수정·삭제·파일 교체를 할 수 있다.

- **AI 사용**
  기업의 승인을 받아 AI가 원본을 읽고(스캔본 포함), 원본 언어를 판단하고, 번역한다. AI 결과는 초안이며, 담당자가 원본과 대조해 확인한 뒤 저장한다.

## 2. 사용자 흐름

| 단계 | 사용자 동작 | 화면에 표시할 결과 |
|---|---|---|
| 1 | CoA 번역 탭 진입 | 가장 최근에 작업한 CoA가 작업 화면에 열린다. 저장된 CoA가 없으면 "신규 CoA 등록" 안내. HOME '이어서 할 작업'에서 들어오면 그 번역본이 열린다. |
| 2 | [신규 CoA 등록] → 제품과 원본 파일 선택, 성적서 이름 입력(선택) → [원본 등록] | 진행 표시 ("원본 올리는 중…" → "원문 글자 읽고 언어 판단 중…") 후 "원본 언어 확인 · 번역 언어 선택" 화면이 나온다. 화면 위에 성적서 이름이 표시되고, 파일 이름과 다르면 원래 파일 이름도 함께 표시된다. |
| 3 | AI가 판단한 원본 언어 확인 (틀리면 변경) → 번역 언어 선택 → [번역 시작] | "번역하는 중…" 후 왼쪽에 원본, 오른쪽에 번역 초안이 열린다. 상태: 번역 초안 생성 |
| 3-1 (원본만 보관) | 같은 화면에서 [원본만 저장] | "원본만 보관함에 저장했습니다." 원본이 보관함에 들어가고 작업 화면에 열린다. 나중에 번역본을 추가할 수 있다. |
| 4 | 원본과 대조하며 번역본 수정 | 수정한 칸이 바로 반영되고 "저장하지 않은 수정 있음"이 표시된다. 숫자가 다르면 '원본 대조 필요' 경고가 나온다. |
| 5 | [임시 저장] | "임시 저장했습니다 — 보관함에 들어갔습니다." 상태: 임시 저장 |
| 6 | [저장하기] → 확인 문구 체크 → 저장 | "저장했습니다 — 원본과 번역본이 보관함에 들어갔습니다." 보관함이 열리고 해당 번역본이 강조된다. 상태: 저장 완료 |
| 7 | [내보내기] → Word 또는 PDF | 모든 쪽에 '번역본 — 원본 아님'이 표시된 파일이 내려받아진다. |
| 8 | [CoA 보관함] → 제품·국가·검색어로 찾기 → 항목 클릭 | 보관함이 닫히고 그 CoA가 작업 화면에 열린다. |

> 원본을 올리기만 하고 저장하지 않은 CoA는 보관함에 나타나지 않고, 작업 화면에 '보관함 저장 전'으로 표시된다. (원본 언어 확인 화면을 X로 닫은 경우)

## 3. 입력

**F1 원본 등록**

| 항목 | 입력 주체·자료 출처 | 형식·단위 | 필수 조건 | 누락·미확인 처리 |
|---|---|---|---|---|
| 제품 | 선택 (제품 관리 탭의 제품 목록) | 제품 | 항상 | 제품을 고르지 않으면 등록 버튼이 꺼진다. |
| 원본 파일 | 직접 업로드 | PDF, Word(.docx), Excel(.xlsx), PNG, JPG, TXT, CSV / 20MB 이하 | 항상 | 형식·크기가 맞지 않거나 내용이 확장자와 다르면 "파일 내용이 확장자와 맞지 않습니다" 등 안내 후 거부 |
| 성적서 이름 | 직접 입력 (선택) | 문자, 200자 이내 | 선택 | 비워 두면 올린 파일 이름(확장자 제외)으로 저장. 입력 칸에 저장될 이름이 흐리게 미리 보인다. 보관함 '원본 편집'에서 변경 가능 |

**F2 글자 읽기·원본 언어 판단**

| 항목 | 입력 주체·자료 출처 | 형식·단위 | 필수 조건 | 누락·미확인 처리 |
|---|---|---|---|---|
| 원본 글자 | 자동 (PDF·Word·Excel은 파일에서 읽고, 스캔본·사진은 AI가 이미지를 읽음) | 문자 | 항상 | 읽기 어려운 곳은 `[원문 확인 필요]`. AI 인식이 실패하면 다시 시도하거나 직접 입력 |
| 원본 언어 | AI 자동 판단 | 언어 | 항상 | 틀리면 담당자가 변경. 판단하지 못하면 "미확인 — 직접 골라 주세요" |

**F3·F4 번역**

| 항목 | 입력 주체·자료 출처 | 형식·단위 | 필수 조건 | 누락·미확인 처리 |
|---|---|---|---|---|
| 번역 언어 | 선택 | 영어(싱가포르 제출용) / 프랑스어(프랑스 제출용) / 한국어. 원본과 같은 언어는 제외 | 번역할 때 | 기본값: 영어 (원본이 영어면 프랑스어) |
| 제출 국가 | 자동 (번역 언어에 따라) | 영어 → 싱가포르, 프랑스어 → 프랑스 | — | 한국어 번역본은 국가 없음. 보관함 정보 편집에서 변경 가능 |
| 번역본 내용 | AI 초안 + 직접 수정 | 원본과 같은 양식 (제목·문단·목록·표·서명란) | 항상 | 읽기 어려운 곳은 `[원문 확인 필요]`, 서명·직인은 `[서명·직인 — 원본 참조]`로 표시 |
| 번역본 구분 이름·바이어 | 직접 입력 | 문자, 200자 이내 | 선택 | 비워 둘 수 있음 |

**F3 AI 번역 규칙**
- 숫자, 단위, 비교 기호(<, ≤, ±), N.D.·LOD·LOQ, 로트 번호, 날짜, 시험 방법 코드는 글자 그대로 둔다. (예: `12.35`는 프랑스어에서도 `12.35`)
- 회사명, 주소, 제품명, 사람 이름은 그대로 둔다.
- 제목, 항목 이름, 글로 쓴 결과(예: Không phát hiện → Not Detected), 문장만 번역한다.
- 읽기 어려운 곳은 추측하지 않고 `[원문 확인 필요]`로 표시한다.

**F6 저장하기 확인**

| 항목 | 입력 주체·자료 출처 | 형식·단위 | 필수 조건 | 누락·미확인 처리 |
|---|---|---|---|---|
| 확인 체크 | 직접 체크 | "원본 성적서와 대조하여 측정값·기준값·단위·기호·LOT·날짜가 원본과 같음을 확인했습니다" (안내: 저장 완료는 번역 정확성에 대한 회사 내부 확인이며, 규제 적합성이나 공인 시험기관의 성적서 발행을 의미하지 않음) | 저장하기 할 때 | 체크하지 않으면 저장 버튼이 꺼진다. |

## 4. 출력과 저장

- **화면에 보여줄 값**

| 기능 | 표시 값 |
|---|---|
| 원본 언어 확인 화면 | 성적서 이름(파일 이름과 다르면 원래 파일 이름 함께), AI가 판단한 원본 언어("AI가 원본을 읽고 판단한 언어입니다. 틀리면 바꿔 주세요."), 번역 언어 선택지(제출 국가 함께 표시), [원본만 저장] · [번역 시작] |
| 작업 화면 상단 | 제품명 · 성적서 이름, 원본 언어, 글자 읽은 방법(PDF 텍스트 / 문서 텍스트 / AI 글자 인식 / 직접 입력), 저장 상태('보관함 저장 전' / '원본 등록 완료'), 번역본 상태, 번역 언어 |
| 원본 칸 (왼쪽) | PDF·이미지는 미리보기, Word·Excel은 읽어 낸 글자 |
| 번역본 칸 (오른쪽) | 원본 양식 그대로의 번역본, 숫자 대조 경고, "저장하지 않은 수정 있음", 저장 완료 시 저장자·저장일. 원본이 교체됐으면 "원본 기준으로 갱신" 안내 |
| 보관함 | 저장한 원본 목록(원본 아래 번역본 펼침), 성적서 이름·제품·국가·등록일·등록자, 고정 표시, 저장된 원본 수. 원본 10건씩, 고정한 원본이 맨 위, 그다음 최근 작업 순 |
| 내보낸 파일 | 모든 쪽에 '번역본 — 원본 아님', 상태, 저장자·저장일, 기준 원본 버전. 숫자는 원문 그대로 |

- **번역본 상태**

| 상태 | 뜻 |
|---|---|
| 번역 초안 생성 | AI 번역 직후 (아직 사람이 안 봄) |
| 임시 저장 | 사람이 고치는 중, 또는 저장 완료본을 다시 고친 경우 |
| 저장 완료 | 저장하기로 확정 |

- **저장 항목과 시점**

| 버튼 | 하는 일 | 번역본 상태 | 보관함 |
|---|---|---|---|
| (올리기만 하고 창 닫기) | 원본 등록 + 글자 읽기 + 원본 언어 판단 | (번역본 없음) | 들어가지 않음 ('보관함 저장 전') |
| 원본만 저장 | 원본만 보관. 등록 직후(원본 언어 확인 화면) 또는 작업 화면에서 사용. 저장하지 않은 번역 초안이 있으면 확인 후 삭제 | (번역본 없음) | 원본만 들어감 |
| 번역 시작 | 고른 언어로 AI 번역 초안 생성 | 번역 초안 생성 | 들어가지 않음 (저장해야 들어감) |
| 임시 저장 | 번역 내용 저장 | 임시 저장 | 처음이면 들어감 |
| 저장하기 | 확인 체크 후 원본·번역본 확정 저장, 저장자 기록 | 저장 완료 | 들어감 |

- **저장 규칙**
  - 성적서 이름은 보관함에 보이는 이름이다. 올린 원본 파일의 이름은 바뀌지 않으며, 원본을 내려받으면 원래 파일 이름으로 받아진다.
  - 원본 언어를 바꾸면 바로 저장된다.
  - 저장 완료된 번역본을 고쳐서 저장하면 다시 '임시 저장'이 된다.
  - 저장 완료된 번역본은 AI로 다시 번역할 수 없다(실수로 덮어쓰는 것 방지).
  - 등록한 원본 파일은 수정하지 않는다. 파일을 교체하면 새 파일로 바꾸고 이전 파일은 기록으로 남긴다. 번역본 상태는 그대로이며, 작업 화면에 '원본 기준으로 갱신' 안내가 뜨고 갱신 전에는 저장 완료를 할 수 없다.
  - 모든 팀원이 저장된 CoA를 다시 열고 수정·삭제할 수 있다.
  - 상태 변경과 수정 내용은 작업 이력에 자동으로 남는다.
  - AI를 쓸 때마다(글자 인식, 언어 판단, 번역) 사용 기록을 남긴다. 원문 내용은 기록하지 않는다.

- **자동 생성 값과 사용자 확인 값의 구분**
  - 자동: 원본 글자, 원본 언어, 성적서 이름(입력하지 않은 경우), AI 번역 초안, 제출 국가, 숫자 대조 경고, 등록자·등록일, 저장자·저장일, 작업 이력
  - 사용자 입력·확인: 성적서 이름(선택), 원본 언어 확인, 번역 언어 선택, 번역본 내용 수정, 저장하기 확인 체크
  - 근거 표시: 원본과 번역본을 나란히 보여준다. 글자를 어떻게 읽었는지(AI 글자 인식 등) 표시하고, AI 번역본에는 사용한 AI 모델을 기록한다.

- **국가 전환과 재접속 시 동작**
  - 제출 국가는 번역 언어에 맞춰 자동으로 붙는다. 같은 원본으로 영어(싱가포르용)와 프랑스어(프랑스용) 번역본을 각각 만들 수 있다.
  - 재접속하면 가장 최근에 작업한 CoA가 열린다.
  - 보관함을 닫았다 열어도 찾기 조건과 검색어는 유지된다.

| 로그인 만료 / 비활성 계정 | 로그인 화면으로 이동하거나 "접근 권한이 없습니다" 안내가 나온다. | 미검증 |

**완료 기준 (사용자 동작 기준)**
- 베트남어 원본 CoA를 올리면 원본 언어가 "베트남어"로 표시되고, 영어를 고르면 싱가포르 제출용 영어 번역본이 원본과 같은 양식으로 나온다.
- 등록할 때 성적서 이름을 입력하면 보관함에 그 이름으로 보이고, 비워 두면 파일 이름으로 보인다.
- 번역 초안의 숫자·로트 번호·날짜가 원문과 같다.
- 스캔본을 올려도 직접 입력 없이 번역까지 진행된다.
- 원본 등록 후 [원본만 저장]을 누르면 원본만 보관함에 들어가고, 나중에 그 원본에서 번역본을 추가할 수 있다.
- 번역본을 고쳐 임시 저장한 뒤 보관함에서 다시 열면 고친 내용이 그대로 있다.
- 저장하기를 하면 HOME '이어서 할 작업'에서 해당 번역본이 사라지고, 저장 완료본을 다시 고치면 HOME에 다시 나타난다.
- 다른 팀원 계정으로 접속해도 저장한 CoA를 열고 수정·삭제할 수 있다.
- 내보낸 Word·PDF의 모든 쪽에 '번역본 — 원본 아님'과 저장자·저장일이 표시된다.
- 보관함에서 제품·국가·검색어(성적서 이름·파일명·로트 번호)로 찾으면 해당 CoA만 나온다.
