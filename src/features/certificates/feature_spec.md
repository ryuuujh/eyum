## 4. 출력과 저장

- 화면에 보여줄 값 또는 생성할 파일과 그 단위
- 저장할 항목과 시점, 누가 다시 열고 수정할 수 있는지
- 해당되는 경우 자동 계산·AI 생성·사용자 확인 값의 구분, 근거 표시 방법
- 국가 전환·재접속 시 기대하는 동작. 합의가 필요한 부분은 ‘미정’으로 표시

## 5. 다른 탭·공통 기능과의 연결

합의한 연결만 적는다. 저장소 전체 연동표는 담당자 간 합의 후 작성한다.

| 가져오거나 제공하는 값 | 읽거나 쓰는 쪽 | 확인 상태·단위 | 합의 상태 |
|---|---|---|---|
| [해당 사항 작성] | [기능명] | [필요한 경우 작성] | [합의 / 미정] |

## 6. 오류와 검증

| 상황 | 사용자에게 기대하는 결과 | 확인 방법·실제 결과 |
|---|---|---|
| 정상 입력 | [기대하는 출력 또는 저장 결과] | [실행 후 작성] |
| 필수 자료 누락 | [안내 문구·진행 가능한 범위] | [실행 후 작성] |
| 저장·외부 조회 실패 등 해당 탭의 오류 | [입력 보존·재시도 등] | [실행 후 작성] |

완료 기준은 사용자 동작으로 작성한다. 예를 들어 제품 탭에서는 “원재료 자료가 부족한 제품을 저장하고 다시 열면 해당 항목에 ‘확인 필요’가 표시된다”처럼 적는다. 미실행 사례는 ‘미검증’으로 남긴다.
