# E:YUM 수출신고 작성 보조 기능 명세

담당자 최유진 · 최종 수정일 2026-11-26 · 상태 초안

## 1. 목적과 범위

이 기능을 쓰는 사람과 상황
- 혜윰 수출 담당자가 쓴다.
- CI/PL을 만든 뒤 UNI-PASS에서 화주 직접 수출신고를 할 때, 유니패스 화면을 옆에 띄워 두고 칸마다 무엇을 넣을지 확인한다.

사용자가 이 탭에서 끝낼 수 있어야 하는 업무
- 유니패스 수출신고서의 공통사항1·공통사항2·란사항·첨부파일 칸별로 넣을 값을 확인한다.
- 넣을 값을 클릭해서 복사한다.
- 유니패스 목록에서 고를 코드를 확인한다.
- 유니패스 안에서 처리할 칸(조회·채번·자동 계산)과 비워 둘 칸을 구분한다.
- CI/PL에서 먼저 보완해야 할 항목을 찾아 CI/PL 탭으로 돌아가 고친다.
- HS가 같은 품목끼리 란을 나누고, 란마다 모델·규격 행을 붙여 넣는다.

이번 시연에 포함할 범위
- 혜윰이 화주로 직접 신고하는 경우 (신고인 = 수출대행자 = 수출화주 = 제조자 = 혜윰)
- 수출국: 싱가포르, 프랑스
- 거래 형태: 유상 일반수출과 무상 견품
- 결제: T/T, L/C. 운송: 해상 LCL, 항공

## 2. 사용자 흐름

| 단계 | 사용자 동작 | 화면에 표시할 결과 |
| --- | --- | --- |
| 1 | 사이드바에서 수출신고서 탭을 연다 | 선택된 제품이 없으면 "선택된 제품이 없습니다. 제품 관리 탭에서 수출할 제품을 선택하세요." 안내만 보인다. 있으면 범례와 공통사항1 하위 탭이 열린다. 하위 탭마다 CI/PL에서 보완할 개수가 빨간 숫자로 붙는다. |
| 2 | 하위 탭(공통사항1 → 공통사항2 → 란사항 → 첨부파일)을 차례로 열고, 유니패스 화면과 같은 순서로 칸을 확인한다 | 칸마다 다섯 가지 중 하나로 보인다: 복사할 값 / [코드] 목록에서 선택 / 유니패스에서 처리 / 비워둠 / CI/PL 보완 필요. 칸 이름에 설명이 있으면 마우스를 올려서 본다. |
| 3 | 값을 클릭한다 | 창 없이 바로 클립보드에 복사된다. 값이 잠깐 초록색으로 바뀌고, 화면 아래에 "복사했어요: (값)" 알림이 뜬다. 복사에 실패하면 "복사하지 못했어요" 알림만 뜬다. |
| 4 | "CI/PL 보완 필요" 칸이 있으면 "CI/PL 수정" 버튼으로 돌아가 고친 뒤 다시 연다 | 고친 값이 바로 반영되고 보완 개수가 줄어든다. |
| 5 | 란사항에서 란 목록의 란을 하나씩 고르고, 모델및규격등록 표를 유니패스에 붙여 넣는다 | 고른 란의 HS부호, 품명, 순중량, 포장개수, 송장부호, 모델·규격 행(품명·수량·단위·단가·금액)이 보인다. HS가 없거나 영문 품명이 없는 란에는 "!"가 붙는다. |
| 6 | 첨부파일 탭에서 "CI/PL 탭에서 받기"를 누른다 | CI/PL 탭으로 이동하고, CI 또는 PL 미리보기가 열린다. 전송 후 처리현황·필증 출력 순서가 안내된다. |

## 3. 입력

이 탭에는 직접 입력하는 칸이 없다. 모든 값은 CI/PL 탭과 제품 관리 탭에서 가져오거나, 고정값 또는 규칙으로 정한다.

| 항목 | 입력 주체·자료 출처 | 형식·단위 | 필수 조건 | 누락·미확인 처리 |
| --- | --- | --- | --- | --- |
| 신고인·수출대행자·수출화주·제조자 상호, 대표자명 | 고정값 (혜윰 / 윤연선) | 문자 | 항상 | 없음 (고정) |
| 수출화주 식별번호 | CI/PL 수출자 Registration No | 사업자등록번호 | 항상 | 미정 (비어 있을 때 표시 없음) |
| 통관고유부호, 신고인부호, 소재지주소, 우편번호, 물품소재지 | 유니패스에서 조회 | - | 항상 | "유니패스에서 처리"로 안내 |
| 구매자 상호 | CI/PL 바이어 회사명 | 영문 문자 | 항상 | "CI/PL에 바이어 회사명 입력 필요" (공통사항1 보완 1건) |
| 구매업체부호 | 유니패스에서 조회. 없으면 해외거래처부호 신청 (CI 필요) | - | 항상 | "유니패스에서 처리"로 안내 |
| 거래구분 | CI 합계 금액으로 자동 결정 | 코드 | 항상 | 금액 > 0이면 11 일반형태 수출, 0이면 92 무상견품 |
| 결제방법 | CI 결제조건·금액으로 자동 결정 | 코드 | 항상 | T/T면 TT, L/C 문구가 있으면 LS, 금액 0이면 GN |
| 인도조건 | CI Terms of delivery | 인코텀즈 | 항상 | 그대로 표시 |
| 목적국 | 공통 수출국 | 국가 코드 (SG / FR) | 항상 | 그대로 표시 |
| 적재항 | CI Port of Loading | 항구 코드 (KRPUS, ICN 등) | 항상 | 목록에 없는 값이면 부산(KRPUS)으로 표시 |
| 운송수단·운송용기 | CI 적재항으로 자동 결정 | 코드 | 항상 | 인천공항이면 40 항공기·ETC, 그 외 10 선박·LC (LCL) |
| 검사희망일 | 유니패스에서 선택 (CI Sailing 날짜 참고) | 날짜 | 항상 | 출항예정일이 있으면 함께 표시 |
| 신용장번호 | 유니패스에서 입력 | 문자 | 결제가 L/C일 때 | L/C가 아니면 "비워둠" |
| 총중량 | PL G.W 합계 | KG, 소수 2자리 | 항상 | 미정 (0일 때 표시 없음) |
| 전체포장개수 | PL 박스 수 합계 | 개, 단위 CT | 항상 | 미정 (0일 때 표시 없음) |
| 결제금액·신고총액 | 유니패스 [수출신고금액계산]. CI 합계를 함께 보여줘 비교 | USD | 항상 | "유니패스에서 처리" + "CI 합계 USD …와 같은지 확인" |
| 운임·운송보험료 | CI 인도조건 | - | FOB가 아닐 때 | FOB면 "비워둠", 아니면 "운임·보험료 확인 필요" (공통사항2 보완 1건) |
| 선박명(편명)·출항예정일자 | CI Vessel / Sailing | 문자 / 날짜 | 선적 확정 후 | 없으면 "선적 확정 후" |
| 란 나누기 | CI/PL 품목을 HS로 묶음 (제품 + 부속물품) | HS 단위 | 항상 | HS가 없는 품목은 따로 한 란. "HS 미확정" (란사항 보완) |
| 란별 HS부호 | 제품 관리 HS / 부속물품 HS | 10단위 | 항상 | 10단위가 아니면 "제품 등록 탭에서 10단위 확정" |
| 수출물품명·거래품명·상표명 | 식품: 이전 혜윰 필증 기준 FOOD·NO. 품목이 하나인 란은 거래품명에 CI 품명 | 영문 | 항상 | 부속물품 영문 품명이 없으면 "CI 품명을 영문으로" (란사항 보완) |
| 순중량·포장개수 | 란에 속한 PL N.W 합·박스 수 합 | KG / CT | 항상 | 포장개수 0이면 "비워둠" |
| 송장부호 | CI Invoice No. | 문자 | 항상 | 그대로 표시 |
| 모델·규격 행 | CI 품목 (품명 대문자, 수량, 단위 PK/PC, 단가, 금액) | USD, 소수 2자리 | 항상 | 부속물품 영문 품명이 없으면 "영문으로: …" |
| Attach여부 | 란의 모델·규격 행 수 | Y / N | 항상 | 99행 초과면 Y |
| 원산지국가 | 고정값 KR | 코드 | 항상 | 없음 (고정) |
| 원산지증명서발급구분 | 유니패스에서 선택 | 코드 | 항상 | "목록에서 선택 (관세사 확인)" |

## 4. 출력과 저장

화면에 보여줄 값
- 유니패스 수출신고서 칸 순서대로 정리한 안내표 (공통사항1, 공통사항2, 란사항, 첨부파일)
- 칸마다 표시하는 다섯 가지
   - 복사할 값: 점선 상자, 클릭하면 창 없이 바로 복사
   - [코드] 이름: 목록에서 선택
   - 유니패스에서 처리: 조회·채번·자동 계산
   - 비워둠
   - CI/PL 보완 필요: 빨간색
- 하위 탭별 보완 개수와 그 목록(마우스를 올리면 보임)
- 란 목록 (NO, 세번부호, 품명, 모델규격)과 고른 란의 모델·규격 표
- 비교용 CI 합계 금액 (USD, 소수 2자리)

생성할 파일
- 없다. CI·PL 파일은 CI/PL 탭에서 받아 유니패스에 첨부한다.

저장
- 이 탭은 자기 데이터를 갖지 않는다. CI/PL 값을 열 때마다 다시 읽어서 보여준다.
- 저장하는 것은 마지막으로 연 하위 탭, 고른 란, 란사항 안의 하위 탭뿐이고, 이 브라우저에 남는다.
- 신고번호·수리 여부·신고필증은 저장하지 않는다. 저장할지는 미정이다.

자동 계산·고정값·사용자 확인 값의 구분
- 자동 결정 (규칙)
   - 거래구분, 결제방법, 운송수단, 운송용기, 적재항 코드, Attach여부
   - 란 나누기, 총중량, 전체포장개수, 란별 순중량·포장개수
   - 위 값마다 판단 근거를 회색 글씨로 함께 보여준다 (예: "CI 결제조건 T/T", "CI 금액 0 (무상 샘플)").
- 고정값
   - 혜윰 상호, 대표자명, 수출자구분 A, 신고구분 H (Paperless), 수출종류 A, 물품상태 N, 원산지 KR, 산업단지코드 999
   - 식품의 FOOD / 상표명 NO는 이전 혜윰 필증을 근거로 표시한다.
- 사용자 확인: 유니패스에서 처리하는 칸과 [코드] 선택은 담당자가 유니패스에서 직접 한다.
- AI: 이 탭에서는 AI를 쓰지 않는다.

국가 전환·재접속
- 국가를 바꾸면 목적국과 CI/PL 값을 다시 읽어 바로 바뀐다.
- 다시 열면 마지막 하위 탭과 란이 그대로 열린다. 란 수가 줄었으면 마지막 란을 연다.

## 6. 오류와 검증

검증 방법: 2026-11-26, Claude 앱 내장 브라우저에서 cipl_decl.html을 열고 예시 데이터를 넣어 확인했다.
- 예시 데이터: 싱가포르, 컵또떡 10박스·단가 2.50, 또떡EZ 5박스·단가 3.00, 바이어 ABC Trading Pte. Ltd., 부속물품은 기본값(카탈로그·종이컵, 무상)
- 상황별로 CI/PL 값을 바꾼 뒤 화면 칸의 글자를 읽어 비교했다.
- 란 전환, 값 복사, 복사 창 닫기는 실제 클릭·키 입력으로 확인했다.
- 실행 중 콘솔 오류는 없었다.

검증 중 발견한 점:
- 부속물품 HS 표기
   - 부속물품 HS가 4911.10.9000처럼 점이 두 개 들어간 채로 표시되고 복사된다.
   - 유니패스 HS부호 칸이 이 형식을 그대로 받는지는 미검증이다. 숫자 10자리나 4911.10-9000으로 바꿔야 할 수 있다.
   - 코드에 4911.10-9000으로 바꾸는 함수(hskFmt)가 있지만 쓰이지 않고 있다.

데모 초기화
- 데모 초기화 함수(resetDemo)로 처음 상태로 되돌리면, 수출신고서 탭을 열 때 S.decl이 없어서 오류가 난다.
- 지금은 이 함수를 부르는 버튼이 화면에 없어서 사용자가 겪을 일은 없다. 다만 초기화 버튼을 다시 넣을 때는 함께 고쳐야 한다.

완료 기준 (사용자 동작 기준):
- CI/PL에서 바이어 회사명을 지우고 이 탭을 열면 공통사항1에 보완 1이 붙고, 다시 입력하면 사라진다. (통과)
- 부속물품 단가를 모두 0으로 두고 제품 단가도 0이면 거래구분이 92 무상견품으로 바뀐다. (통과)
- 란사항에서 란을 바꾸면 그 란의 HS·순중량·모델·규격 행이 CI/PL 값과 같게 바뀐다. (통과)
- 값을 클릭해 복사한 뒤 유니패스 칸에 붙여 넣으면 화면에 보이는 값과 같다. (미검증)
- 첨부파일 탭의 "CI/PL 탭에서 받기"를 누르면 CI/PL 탭의 해당 미리보기가 열린다. (통과)
