# HOME 탭 기능명세서

## 1. 목적과 범위

- **사용자와 상황**
  식품 수출 담당 팀원이 로그인하면 가장 먼저 보는 화면이다. 오늘 처리할 일, 팀 일정, 환율, 바이어 현지 시각, 팀 공유 메모, 서류 탭에서 진행 중인 작업, 규제 변경 소식을 한 화면에서 확인한다.

- **사용자가 이 탭에서 끝낼 수 있어야 하는 업무**
  1. 주요 통화의 원화 환율(은행 고시 매매기준율) 확인
  2. 바이어 국가의 현지 시각과 서울과의 시차 확인
  3. 업무 일정 등록·수정·삭제와 캘린더 확인
  4. 다가오는 일정을 D-day로 확인
  5. 특이사항 메모 작성·저장, 해결 처리
  6. 서류 관련 탭(라벨링, C/I·P/L, 수출신고서, CoA)에서 끝내지 않은 작업과 마지막 작업 내용을 확인하고 해당 작업으로 바로 이동
  7. 국가별 규제 변경 점검 결과 확인과 확인 완료 처리

- **이번 시연 범위**
  HOME 기능 전체 (아래 F1~F9)

- **기능 구성**

| 번호 | 기능 | 내용 |
|---|---|---|
| F1 | 환율 | 한국수출입은행 고시 매매기준율로 원화 환율 표시. 관심 통화 선택과 저장, 자동·수동 새로고침 |
| F2 | 바이어 현지 시각 | 도시별 현재 시각과 서울과의 시차. 도시 추가·삭제와 저장 |
| F3 | 업무 캘린더 | 월 단위 캘린더. 월 이동, 전체 / 내 일정 보기, 국가 필터 |
| F4 | 일정 등록·수정·삭제 | 일정을 입력해 저장하면 DB에 저장되고 캘린더와 다가오는 일정에 바로 반영 |
| F5 | 다가오는 일정 | 끝나지 않은 일정 중 가까운 5건을 D-day로 표시 |
| F6 | 특이사항 메모 | 메모 작성·저장·수정·삭제, 해결 처리, 국가·업무별 필터. 다른 탭과 연동하지 않고 HOME에서 작성·저장·조회한다. |
| F7 | 이어서 할 작업 | 서류 관련 탭(라벨링, C/I·P/L, 수출신고서, CoA)의 미완료 작업 목록, 마지막 작업 내용과 시각, 작업 화면으로 이동. 제품 관리 탭은 표시하지 않는다. |
| F8 | 규제 업데이트 현황 | 식품 규제 탭의 국가별 점검 결과 표시, 확인 완료 처리 |
| F9 | 상단 수출국 선택 | 선택한 수출국을 전체 탭에 함께 적용 |

- **권한**
  관리자와 팀원을 구분하지 않는다. 로그인한 팀원은 모두 같은 권한으로 HOME의 모든 데이터를 조회·등록·수정·삭제할 수 있다.

## 2. 사용자 흐름

| 단계 | 사용자 동작 | 화면에 표시할 결과 |
|---|---|---|
| 1 | 로그인 후 HOME 진입 | 환율, 현지 시각, 이번 달 캘린더(오늘 날짜 강조), 다가오는 일정, 특이사항 메모, 이어서 할 작업, 규제 업데이트 현황. 데이터가 없는 카드에는 빈 상태 안내 문구 (예: "다가오는 일정이 없습니다. 캘린더에 일정을 등록하면 자동으로 표시됩니다.") |
| 2 | 환율 카드에서 통화 선택, 현지 시각 카드에서 도시 추가·삭제 | 바로 반영되고, 다음 접속 때도 그대로 유지 |
| 3 | "일정 등록" 버튼 또는 날짜 더블클릭 → 입력 → 저장 | 캘린더에 일정 막대가 표시되고, 다가오는 일정에 D-day로 추가. 입력 오류가 있으면 해당 칸에 안내 문구 |
| 4 | 캘린더나 다가오는 일정에서 일정 클릭 | 일정 상세 팝업에서 수정·삭제. 삭제할 때는 확인 창이 나온다. |
| 5 | 메모 입력 후 "메모 남기기" | 메모 목록 맨 위에 추가되고 미해결 건수 증가 |
| 6 | 메모의 "해결 완료" 클릭 | 해결 상태로 바뀌고 해결한 사람과 시각이 기록됨. "미해결로 되돌리기" 가능 |
| 7 | 이어서 할 작업에서 항목 클릭 | 해당 서류 탭의 작업 화면으로 이동해서 이어서 작업 |
| 8 | 규제 업데이트 항목에서 "확인 완료" 클릭 | 확인 완료 상태로 바뀌고 확인한 사람과 시각이 기록됨. 원문 링크로 이동 가능 |

## 3. 입력

**F4 일정**

| 항목 | 입력 주체·자료 출처 | 형식·단위 | 필수 조건 | 누락·미확인 처리 |
|---|---|---|---|---|
| 일정 제목 | 직접 입력 | 문자, 200자 이내 | 항상 | "일정 제목을 입력해 주세요." |
| 일정 유형 | 선택 | 전시회·상담회 / 해외 출장 / 바이어 미팅 / 서류 제출기한 / 기타 | 항상 | 기본값으로 저장 |
| 시작 날짜 | 선택 | 날짜 (YYYY-MM-DD) | 항상 | "시작 날짜를 입력해 주세요." |
| 종료 날짜 | 선택 | 날짜 (YYYY-MM-DD) | 항상 | "종료일은 시작일보다 빠를 수 없습니다." |
| 종일 여부 | 선택 | 예 / 아니오 | 항상 | 기본값: 종일 |
| 시작·종료 시간 | 선택 | 시:분 | 종일이 아닐 때 | "종료 시간은 시작 시간보다 늦어야 합니다." |
| 시간대 | 선택 | 도시별 현지시간 | 종일이 아닐 때 | 기본값: 한국시간. 바이어 미팅은 상대 도시 시간으로 입력 가능 |
| 관련 국가 | 선택 | 국가 | 선택 | 비워 둘 수 있음 |
| 상세 메모 | 직접 입력 | 문자, 5000자 이내 | 선택 | 예: 부스 번호, 담당 바이어, 준비물 |

**F6 특이사항 메모**

| 항목 | 입력 주체·자료 출처 | 형식·단위 | 필수 조건 | 누락·미확인 처리 |
|---|---|---|---|---|
| 메모 내용 | 직접 입력 | 문자, 2000자 이내 | 항상 | "메모 내용을 입력해 주세요." |
| 관련 국가 | 선택 (기본값: 상단 수출국) | 국가 또는 "공통" | 선택 | 비워 두면 "공통" |
| 관련 업무 | 선택 (HOME 안에서 분류용) | 제품 관리 / 식품규제 / 라벨링 / C/I·P/L / 수출신고서 / CoA / 기타 | 항상 | 기본값: 기타 |

**F1·F2·F9 사용자 설정**

| 항목 | 입력 주체 | 형식·단위 | 필수 조건 | 누락·미확인 처리 |
|---|---|---|---|---|
| 관심 통화 | 선택 | USD, EUR, SGD, CNY, JPY, HKD, GBP, THB, AUD, CAD 중 선택 | 최소 1개, 최대 10개 | 기본값: USD·EUR·SGD |
| 현지 시각 도시 | 선택 | 서울, 싱가포르, 파리, 상하이, 두바이, 뉴욕, 로스앤젤레스, 도쿄, 홍콩, 호찌민, 방콕, 런던, 시드니 중 선택 | 최대 12개, 서울은 항상 포함 | 기본값: 서울·싱가포르·파리 |
| 상단 수출국 | 선택 | 국가 | 항상 | 기본값: 싱가포르 |

## 4. 출력과 저장

- **화면에 보여줄 값**

| 기능 | 표시 값과 단위 |
|---|---|
| F1 환율 | 외화 1단위당 원화 (소수점 2자리, JPY는 100엔 기준), 고시일, 갱신 시각, 출처 (한국수출입은행 매매기준율) |
| F2 현지 시각 | 도시별 현재 시각, 서울과의 시차 (예: "1시간 느림") |
| F3 캘린더 | 일정 유형별 색상 막대. 여러 날짜 일정은 하나로 이어진 막대, 하루 표시 한도를 넘으면 "+N" |
| F5 다가오는 일정 | 진행 중 / 오늘 / D-숫자, 일정 제목, 날짜 |
| F6 메모 | 내용, 국가, 관련 업무, 작성일, 작성자, 해결 여부, 미해결 건수 |
| F7 이어서 할 작업 | 서류 종류 (라벨링 / C/I·P/L / 수출신고서 / CoA), 제목, 국가, 제품명, 상태 (임시 저장 / 작성 중 / 수정 중 / 검수 대기 / 보완 필요), 마지막 작업 내용, 마지막 저장 시각, 이어하기 버튼 |
| F8 규제 업데이트 | 국가, 출처 기관, 제목, 상태 (확인 필요 / 변경 없음 / 확인 완료), 점검일, 확인자, 원문 링크 |

- **저장 항목과 시점, 권한**

| 데이터 | 저장 시점 | 볼 수 있는 사람 | 수정·삭제할 수 있는 사람 |
|---|---|---|---|
| 일정 | 일정 팝업에서 "저장"을 누를 때 | 모든 팀원 | 모든 팀원 |
| 특이사항 메모 | "메모 남기기"를 누를 때 | 모든 팀원 | 모든 팀원 (해결 처리 포함) |
| 관심 통화·현지 시각 도시 | 바꾸는 즉시 | 본인 | 본인 |
| 상단 수출국 | 바꾸는 즉시 | 본인 | 본인 |
| 규제 확인 처리 | "확인 완료"를 누를 때 | 모든 팀원 | 모든 팀원 |
| 이어서 할 작업 | 각 서류 탭에서 저장할 때 (HOME은 조회만) | 모든 팀원 | 각 서류 탭에서 처리 |

- **자동으로 정해지는 값과 사용자 입력값의 구분**
  - 자동: 환율(한국수출입은행 API), D-day(오늘 날짜는 한국 시간 기준), 현지 시각과 시차, 작성자, 작성일, 수정 시각, 해결자, 해결 시각, 확인자, 확인 시각
  - 사용자 입력: 일정, 메모, 통화·도시 선택, 수출국 선택, 해결·확인 처리
  - 근거 표시: 환율은 출처와 고시일을, 규제 점검 결과는 출처 기관과 원문 링크를 함께 표시한다.
  - 작성자는 자동으로 기록되며 바꿀 수 없다.

- **재접속과 국가 전환 시 동작**
  - 일정, 메모, 통화·도시 설정은 재접속하거나 다른 기기에서 접속해도 유지된다.
  - 자정(한국 시간)이 지나면 "오늘" 표시와 D-day가 자동으로 바뀐다.
  - 환율은 한국수출입은행이 영업일 오전 11시쯤 고시하는 값으로 하루 1회 갱신된다. 고시 전이나 주말·공휴일에는 직전 영업일 환율을 고시일과 함께 표시한다. 화면은 자동으로 새로 불러오고, 수동 새로고침도 할 수 있다.
  - 상단 수출국을 바꾸면 메모 작성 시 기본 국가에 반영되고, 다른 탭에도 같은 국가가 적용된다.
  - 상단 수출국을 바꿨을 때 캘린더와 규제 현황도 그 국가로 자동으로 걸러 보여줄지: **미정**

## 5. 다른 탭·공통 기능과의 연결

| 가져오거나 제공하는 값 | 읽거나 쓰는 쪽 | 확인 상태·단위 | 합의 상태 |
|---|---|---|---|
| 원화 환율 | 한국수출입은행 환율 API → HOME | 영업일 하루 1회 고시, 매매기준율 | 합의 |
| 미완료 작업 (서류 종류, 제목, 제품, 국가, 상태, 이동 경로) | 라벨링·C/I·P/L·수출신고서·CoA 탭이 기록 → HOME은 조회만 | 상태 5종 (완료·해당 없음은 미표시) | 미정 |
| 마지막 작업 내용 (작업 내용, 시각) | 각 서류 탭이 저장할 때 기록 → HOME은 조회만 | 짧은 문구 | 미정 |
| 규제 점검 결과 (국가, 출처, 제목, 원문 링크, 점검일, 변경 여부) | 식품 규제 탭이 기록 → HOME은 조회와 확인 처리 | 확인 필요 / 변경 없음 / 확인 완료 | 미정 |
| 상단 수출국 선택값 | HOME ↔ 전체 탭 | 국가 | 미정 |
| 사용자 정보 | 공통 로그인 → HOME | 로그인한 팀원 (권한 구분 없음) | 합의 |

※ 캘린더 일정과 특이사항 메모는 다른 탭과 연동하지 않고 HOME에서만 작성·저장·조회한다.

## 6. 오류와 검증

| 상황 | 사용자에게 기대하는 결과 | 확인 방법·실제 결과 |
|---|---|---|
| 정상 입력: 일정 저장 | 캘린더와 다가오는 일정에 바로 표시되고, 재접속해도 유지된다. | 미검증 |
| 정상 입력: 메모 저장 | 목록 맨 위에 추가되고 미해결 건수가 늘어난다. 재접속해도 유지된다. | 미검증 |
| 필수 항목 누락 | 해당 칸에 안내 문구가 나오고 저장되지 않는다. 입력한 내용은 그대로 남는다. | 미검증 |
| 잘못된 날짜·시간 | "종료일은 시작일보다 빠를 수 없습니다." 등 안내 문구가 나오고 저장되지 않는다. | 미검증 |
| 일정·메모 삭제 | 삭제 확인 창이 나오고, 확인을 눌러야 삭제된다. | 미검증 |
| 환율 조회 실패 | 오류 문구와 "다시 시도" 버튼이 나온다. 임의의 값은 표시하지 않고, 이전에 받은 값이 있으면 고시일과 함께 유지한다. | 미검증 |
| 환율 고시 전·주말·공휴일 | 직전 영업일 환율을 고시일과 함께 표시한다. | 미검증 |
| 저장 실패 (네트워크 등) | 오류 문구가 나오고 입력 내용은 유지된다. 다시 저장할 수 있다. | 미검증 |
| 서류 탭에 저장된 작업이나 규제 점검 결과가 없음 | 빈 상태 안내 문구 (예: "이어서 할 작업이 없습니다.") | 미검증 |
| 로그인 만료 / 비활성 계정 | 로그인 화면으로 이동하거나 "접근 권한이 없습니다" 화면이 나온다. | 미검증 |

**완료 기준 (사용자 동작 기준)**
- 일정을 등록하고 새로고침하면 캘린더와 다가오는 일정에 그대로 보이고, D-day가 맞게 표시된다.
- 다른 팀원 계정으로 접속해도 등록한 일정과 메모가 보이고, 수정·삭제할 수 있다.
- 메모를 해결 처리한 뒤 다시 접속하면 해결 상태와 해결한 사람이 표시된다.
- 통화와 도시를 바꾼 뒤 다시 접속해도 설정이 유지된다.
- 환율 카드에 한국수출입은행 매매기준율과 고시일이 표시된다.
- 이어서 할 작업 항목을 누르면 해당 서류 탭의 그 작업 화면이 열린다.
