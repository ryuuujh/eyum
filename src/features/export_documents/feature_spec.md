# E:YUM CI·PL 초안 작성 기능 명세

담당자 최유진 · 최종 수정일 2026-11-26 · 상태 초안

## 1. 목적과 범위

이 기능을 쓰는 사람과 상황
- 혜윰 수출 담당자가 쓴다.
- 제품 관리 탭에서 수출할 제품을 고른 뒤, 바이어에게 보낼 상업송장(CI)과 포장명세서(PL)를 만든다.
- 박람회 참가처럼 카탈로그·판촉물을 함께 보낼 때도 쓴다.

사용자가 이 탭에서 끝낼 수 있어야 하는 업무
- 바이어 PI·PO 파일을 올려 바이어 정보·조건·품목을 한 번에 채운다.
- 바이어(Consignee) 정보, 선적 정보, 은행 정보, 수출자(Shipper) 정보를 입력하고 확인한다.
- 제품별 박스 수와 단가를 넣고 수량·금액·중량을 확인한다.
- 부속물품(카탈로그·판촉물)과 박스(Case)를 정리한다.
- 누락·불일치 항목을 보고 고친다.
- 혜윰 양식 그대로 CI·PL을 미리 보고, 엑셀(CI·PL 시트)이나 PDF로 저장한다.
- 작업을 초안으로 저장했다가 다시 불러온다.

이번 시연에 포함할 범위
- 수출국: 싱가포르(SG), 프랑스(FR)
- 결제·인도조건 기본값: T/T, FOB
- 위 업무 전부. 다만 AI 주소 분리는 API 키가 없으면 규칙 분리로 동작한다.
- 제외: 실제 로그인·권한, 서버 저장(현재는 브라우저 localStorage), 대표 공유 화면

## 2. 사용자 흐름

| 단계 | 사용자 동작 | 화면에 표시할 결과 |
|---|---|---|
| 1 | [진입 또는 선택] | [첫 화면·빈 상태] |
| 2 | [입력 또는 조회] | [중간 결과·확인 필요 항목] |
| 3 | [저장 또는 출력] | [완료 안내·다시 확인하는 방법] |
| 단계 | 사용자 동작 | 화면에 표시할 결과 |
| --- | --- | --- |
| 1 | 사이드바에서 CI / PL 탭을 연다 | 제품 관리 탭에서 고른 제품이 없으면 "선택된 제품이 없습니다. 제품 관리 탭에서 수출할 제품을 선택하세요." 안내만 보인다. 있으면 PI·PO 불러오기, 바이어, 선적, 은행, 수출자, 제품, 부속물품 카드와 미리보기가 보인다. |
| 2 | (선택) PI·PO 엑셀·CSV를 끌어다 놓거나 "예시 PI로 해보기"를 누른다 | 읽는 중 표시 → "PI 내용 확인" 창에 항목별로 지금 값과 PI에서 읽은 값이 나란히 나온다. 체크한 항목만 "N개 항목 채우기"로 반영된다. 못 찾은 항목은 "못 찾음"으로 표시된다. |
| 3 | 바이어 정보를 입력한다. 주소는 한 줄로 붙여 넣고 "주소 분리"를 누를 수 있다 | 주소 1·2, 도시, 우편번호 칸이 채워진다. 형식이 틀린 칸은 빨간 테두리와 오류 배지가 붙는다. 아래에 CI/PL CONSIGNEE 표기가 자동 조립돼 보인다. |
| 4 | 선적 정보, 은행 정보, 수출자 정보를 입력하거나 확인한다 | 적재항·최종 도착지·양하항은 국가별 목록에서 고르고, 목록에 없으면 "직접 입력"을 쓴다. 은행·수출자 정보는 접었다 펼 수 있다. |
| 5 | 제품별 Box(CTN)와 단가를, 부속물품의 수량·단가·중량·박스 번호를 입력한다 | Pack 수량, 금액, N.W·G.W, 박스별 CBM·총중량, TOTAL이 바로 다시 계산된다. 부속물품 단가가 0이면 F.O.C로 표시된다. |
| 6 | 누락·불일치 카드를 확인한다 | "누락·불일치 N건"과 항목 목록, 또는 "누락 항목 없음"이 보인다. |
| 7 | 미리보기에서 Commercial Invoice / Packing List를 바꿔 보고, 엑셀 또는 PDF로 저장한다 | 혜윰 양식과 같은 칸 배치로 미리보기가 나온다. 엑셀은 `{Invoice No.}_CI_PL.xlsx`(CI·PL 두 시트)로 받아진다. PDF는 인쇄 창이 열린다. |
| 8 | "초안 저장"을 누르고 이름을 정한다. 나중에 "이전 작업"에서 불러온다 | 저장 완료 알림. 같은 이름이 있으면 덮어쓸지 묻는다. 불러오면 지금 화면의 CI/PL 내용이 그 초안으로 바뀐다는 확인을 거친다. |

## 4. 출력과 저장


화면에 보여줄 값
- 제품 표: Pack(EA) = Box × 박스당 입수, 금액 = Pack × 단가, N.W·G.W = Box × 박스 중량(kg), TOTAL
- 부속물품 표: 금액(0이면 F.O.C), N.W·G.W, TOTAL
- 박스 표: 박스별 CBM(소수 2자리), G.Weight(담긴 품목 G.W 합), 전체 CASES 수
- 누락·불일치 목록
- CI·PL 미리보기 (혜윰 양식과 같은 칸 배치, 금액 USD, 중량 kg)

생성할 파일
- 엑셀: {Invoice No.}_CI_PL.xlsx. CI 시트와 PL 시트로 되어 있고, 병합·테두리·글꼴(Verdana)·열 너비가 혜윰 양식과 같다. 금액·합계는 엑셀 수식이라 파일에서 고쳐도 다시 계산된다.
- PDF: 지금 보고 있는 CI 또는 PL을 브라우저 인쇄로 저장한다.

서류에 들어가는 규칙
- CI Shipper Tel과 하단 서명란은 CI Tel, PL Shipper Tel은 PL Tel을 쓴다.
- 날짜 표기는 CI Invoice Date가 24/Nov/2026, PL Date·Sailing이 24-Nov-2026이다.
- CI 품명은 "영문 품명 + 중량(g)"이다. 부속물품 단가가 0이면 "(F.O.C · No Commercial Value)"를 붙인다.
- PL은 품목마다 "HS CODE : …" 줄 다음에 품목 줄이 온다. Pack 합계에는 제품만 넣고, 단위가 다른 부속물품은 뺀다.
- Final Destination은 도시만 고르고 서류에는 ", 국가명"을 붙인다. 싱가포르는 붙이지 않는다.

저장
- 입력값은 바뀔 때마다 이 브라우저에 자동 저장되고, 다시 열면 그대로 남아 있다.
- "초안 저장"은 CI/PL 내용과 선택 제품, 국가를 이름 붙여 저장한다. 빈칸이 있어도 저장된다.
- 초안은 만든 사람만 보고, 불러오고, 삭제할 수 있다. 대표 공유는 데이터 구조(share)만 있고 공유하는 화면은 아직 없다.
- 수정·확인 이력은 최근 60건까지 시간·사용자와 함께 남는다.

자동 계산·AI·사용자 확인 값의 구분
- 자동 계산: Pack, 금액, 중량, CBM, 합계, CONSIGNEE 표기, 날짜 표기
- AI: 주소 한 줄 분리만 한다. AI에는 주소 문자열만 보내고 회사명·담당자·전화·이메일·파일 내용은 보내지 않는다. 키가 없거나 실패하면 브라우저 안 규칙으로 나눈다.
- 사용자 확인: PI에서 읽은 값은 확인 창에서 체크한 것만 반영한다. HS Code는 사람이 확정한다.
- 근거 표시: 확인 창에 AI 사용 여부가 표시된다. 화면 안 별도 근거 표시는 미정이다.

국가 전환·재접속
- 국가를 바꾸면 Final Destination·Port of Discharge가 비워지고 새 국가 기본값을 쓴다. 주소·전화 형식 검사도 그 국가 기준으로 바뀐다.
- 초안을 불러오면 초안을 저장할 때의 국가로 바뀐다.
- 국가별로 CI/PL을 따로 보관할지는 미정이다 (현재는 한 벌).

| 정상 입력 (싱가포르, 제품 2개, 부속물품 2개) | 미리보기와 엑셀이 혜윰 양식과 같은 칸·병합·테두리로 나오고, 금액·중량 합계가 화면 표와 같다 | 브라우저 미리보기 확인, 같은 코드로 Node에서 만든 엑셀을 openpyxl로 확인함. 병합·값·수식·PL 품목 줄 테두리·가운데 정렬·PL Tel 정상. 브라우저의 [엑셀 내보내기] 버튼으로 받는 것은 **미검증** |
| 제품을 하나도 고르지 않음 | "선택된 제품이 없습니다…" 안내만 보이고 다른 입력은 막힌다 | 미검증 |
| 바이어 필수 정보 누락·형식 오류 | 해당 칸에 빨간 테두리·오류 배지, 누락 카드에 항목이 나온다. 미리보기·저장은 계속할 수 있다 | 미검증 |
| PL 번호·날짜·선박 미입력, 단가 0, HS 없음, G.W < N.W | 누락·불일치 카드에 항목별 문구가 나온다 | 미검증 |
| 부속물품 단가 0 | CI에 "(F.O.C · No Commercial Value)", 금액 0으로 나온다 | 미리보기 확인함 |
| 주소 분리 (AI 키 없음) | 규칙으로 주소 1·2·도시·우편번호가 채워진다 | 미검증 (예시 주소로 확인 필요) |
| 주소 분리 (AI 실패·15초 초과) | 규칙 분리로 바로 넘어가고 입력은 그대로 남는다 | 미검증 |
| PI 파일이 .xls이거나 PDF | "xlsx로 다시 저장" 또는 "엑셀·CSV만 읽을 수 있어요" 안내. 화면 값은 바뀌지 않는다 | 미검증 |
| PI에서 내용을 못 찾음 | "PI 내용을 찾지 못했어요" 안내. 화면 값은 바뀌지 않는다 | 미검증 |
| 인터넷이 끊겨 엑셀 라이브러리를 못 불러옴 | "엑셀 라이브러리를 불러오지 못했습니다. 인터넷 연결을 확인해 주세요." 입력은 그대로 남는다 | 미검증 |
| 초안 저장 후 다른 값으로 바꾸고 다시 불러옴 | 저장했던 값과 국가로 돌아간다 | 미검증 |

완료 기준 (사용자 동작 기준):
- 예시 PI를 불러와 "채우기"를 누르면 바이어 회사명·주소·조건·품목 박스 수가 채워진다.
- 바이어 전화번호를 형식에 맞지 않게 넣으면 그 칸에 "형식 오류"가 표시되고 누락 카드에 같은 항목이 나온다.
- 엑셀을 받아 열면 CI·PL 두 시트가 혜윰 양식과 같고, 단가를 고치면 금액·합계가 다시 계산된다.
- 초안을 저장하고 새로 고친 뒤 "이전 작업"에서 불러오면 저장한 값이 그대로 돌아온다.
