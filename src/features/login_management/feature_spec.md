# 내 계정

- **입력** 기존 팀 계정의 이메일과 비밀번호로 Supabase Auth에 로그인한다. 프로필 이름과 소속은 현재 사용자의 메타데이터에서 읽고 이메일은 같은 계정에서 가져온다.
- **사이드바** 제품 관리 아래에 이름 첫 글자 아바타, 이름, 소속을 표시하고 옆에 로그아웃 버튼을 둔다. 이름이 비어 있으면 이메일, 소속이 비어 있으면 ‘내 계정’을 표시한다. 로그인 전에는 계정 아이콘과 로그인 안내를 표시한다.
- **계정 화면** 프로필을 누르면 선택한 수출국을 유지해 내 계정으로 이동한다. 로그인하면 본인의 이름·소속·이메일을 확인할 수 있다. 연결 설정이 없을 때는 팀 계정 연결 준비 상태를 표시한다.
- **권한** 계정 표시 범위는 현재 로그인한 사용자 본인이다. 대표·직원의 업무별 권한과 전체 탭 데이터 연동은 미정이다.
- **검증** 로그인·로그아웃 뒤 사이드바와 계정 화면이 함께 갱신되는지, 새로고침해도 로그인 상태가 복원되는지, 잘못된 로그인과 연결 미설정 상태를 구분하는지 확인한다. 좁은 화면과 접힌 사이드바에서도 계정에 접근할 수 있어야 한다.
