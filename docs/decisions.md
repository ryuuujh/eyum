# E:YUM 결정 사항

2026-11-26 기준

| 주제 | 내용 | 상태 |
|---|---|---|
| 서비스명 | 대시보드·발표용 `E:YUM`(이윰), 개발 폴더와 저장소 `eyum` | 확정 |
| 기술 기반 | Next.js, TypeScript, npm. 회원가입·저장은 Supabase, AI는 공통 서버를 통한 OpenAI API 호출 | 방향 합의 |
| 공통 관리 | 공통 개발환경·DB·GitHub PR은 유정현 주담당, 채주현 부담당 | 확정 |
| 디자인 | MediCore의 글자 위계·카드 배치와 혜윰의 진녹색을 초기 권장안으로 삼는다. 담당 화면의 디자인은 기능 담당자가 자유롭게 조정한다. [공통 디자인 가이드](design_system.md) | 초기 공통 UI 적용 · 기업 시안 검토 예정 |
| 제품 등록 | 구성품 단위로 입력하고 수출국과 독립적으로 관리. 규제 탭에는 값과 확인 상태를 전달 | 연동 방향 합의 |
| DB·저장 | 대표·직원 세부 권한, 공통 ID 규격, 전체 탭 간 데이터 연동표 | 미정 |
| 배포·인수인계 | 팀 개발·발표 환경으로 운영하고 이관 시 기업 조직으로 이전. 실제 서비스 계정과 DB 연결은 별도 구성 | 방향 합의 |
